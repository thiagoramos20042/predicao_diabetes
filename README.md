# Diabetes | Estudo de classificação supervisionada

Estudo de regressão logística com exploração de atributos e avaliação de um classificador.

**Data Science** · Notebook

[← Data Science, IA e Automações · Thiago Oliveira](https://github.com/thiagoramos20042/thiagoramos20042) · [Catálogo de projetos](https://github.com/thiagoramos20042/thiagoramos20042/blob/main/PROJETOS.md)

## Objetivo

Praticar preparação de dados, separação de treino/teste e leitura de métricas de classificação em um conjunto de dados de diabetes.

## O que você encontra

- Exploração das variáveis disponíveis no dataset.
- Treinamento de regressão logística.
- Avaliação por matriz de confusão e relatório de classificação.

## Tecnologias

Python · pandas · NumPy · seaborn · Matplotlib · scikit-learn
